# Visual QA checklist

Review these viewport sizes after every material layout change:

- 320×568
- 375×812
- 390×844
- 430×932
- 768×1024
- 1024×768
- 1280×800
- 1440×900
- 1920×1080

Check Hero, Method, UNNI case, Services, Process, About, Education, Contact, Footer, and the open mobile menu.

Look specifically for:

- horizontal overflow;
- poor Cyrillic line breaks;
- orphaned words and prepositions;
- clipped focus outlines;
- incorrect portrait crops;
- sticky elements in short landscape viewports;
- overlap from the mobile contact bar;
- layout shift after font loading;
- animation flashes when the intro is skipped;
- excessive oxblood or repeated card-like compositions.
